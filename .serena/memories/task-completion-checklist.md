# Task Completion Checklist

## TDD 워크플로우 (필수)

코드 작성이 필요한 모든 작업에 아래 프로세스를 따릅니다.

### 1단계: 테스트 작성 (Red Phase)
- 요구사항 분석 후 테스트 시나리오 목록 작성
- 실패하는 테스트 코드 작성
- 테스트 파일: `src/**/*.test.ts` 또는 `src/**/*.test.tsx`

### 2단계: 테스트 리뷰
- AI 테스트 리뷰 에이전트 호출
- PASS 판정 전까지 진행 금지

### 3단계: 구현 (Green Phase)
- 테스트 통과하는 최소한의 코드 작성
- `pnpm test` 실행하여 통과 확인

### 4단계: 코드 품질 체크
```bash
pnpm lint
pnpm typecheck
```

### 5단계: 성능 리뷰 (React 대상)
- React 컴포넌트/데이터 페칭 변경 시 성능 리뷰

### 6단계: 리팩토링 (Refactor Phase)
- 테스트 통과 상태 유지하면서 코드 개선
- 중복 제거, 네이밍 개선, 구조 단순화

### 7단계: 커밋 (선택적)
- 사용자 승인 후 진행
- Conventional Commits 형식 준수

### 8단계: PR 생성 (선택적)
- 사용자 승인 후 PR 생성 및 CI 모니터링

## 최종 체크리스트

커밋 전 확인:
- [ ] 모든 테스트 통과 (`pnpm test`)
- [ ] 린트 에러 없음 (`pnpm lint`)
- [ ] 타입 에러 없음 (`pnpm typecheck`)
- [ ] console.log 제거
- [ ] 주석 처리된 코드 제거
- [ ] TODO 없음 (또는 티켓 연결됨)
- [ ] 문서 업데이트 (필요시)

## 적용 대상
- ✅ 새 기능 구현
- ✅ 기존 기능 수정/확장
- ✅ 버그 수정
- ✅ 리팩토링
- ✅ API 엔드포인트 추가/수정
- ✅ 컴포넌트 추가/수정
- ✅ 유틸리티 함수 추가/수정

## 제외 대상
- ❌ 설정 파일 수정 (config, env 등)
- ❌ 스타일만 변경 (CSS, Tailwind 클래스)
- ❌ 타입 정의만 추가
- ❌ 주석/문서 수정
- ❌ 패키지 설치/업데이트
