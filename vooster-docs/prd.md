## 1. 제품 개요 (Product Overview)

### 1.1 제품 정의

**Sdeume AI (스드메 AI)** 는 스튜디오 촬영을 생략하거나 실패한 커플을 위해, 집에서 촬영하듯 **온라인으로 웨딩 화보를 즉시 생성**해주는 **AI 기반 버추얼 스튜디오**입니다.
사용자는 시간·장소·예산의 제약 없이 "나를 주인공으로 한 하이엔드 웨딩 화보"를 생성하여 모바일 청첩장이나 식전 영상에 활용할 수 있습니다.

### 1.2 핵심 가치 제안 (UVP)

- **Stress-Free Wedding Prep (스트레스 해소):** 스드메 준비의 스트레스를 0으로.
- **Sub-Album Solution (서브 앨범/보완재):** "못 해본 컨셉, AI로 채우는 2% 아쉬움.
- **Active Directing:** 정해진 포즈가 아닌, 내가 원하는 분위기와 배경을 선택하는 주체적 경험.

## 2. 타겟 사용자 (Target Audience)

### 🥇 1순위: 컨셉 확장형 (The Concept Expander)

> **"스튜디오 촬영은 했지만, 2% 부족한 '로망'을 채우고 싶어요."**

- **정의:** 기존 스튜디오 촬영은 완료했으나, 물리적 제약(시간/비용/날씨)으로 인해 시도하지 못한 **'서브 컨셉'**에 아쉬움이 남은 고객.
- **구체적 상황 (Situation):**
  - "제주도 야외 스냅을 찍고 싶었지만 휴가를 못 냄."
  - "한복/캐주얼 컷을 찍으려다 추가금 압박으로 포기함."
- **핵심 니즈:** 메인 앨범 외에 **다양성을 더해줄 서브 앨범** 확보.

### 🥈 2순위: 결과물 대체형 (The Replacement Seeker)

> **"돈은 돈대로 썼는데, 청첩장에 넣을 '쓸 만한 사진'이 없어요."**

- **정의:** 고가의 스튜디오 촬영을 진행했음에도 결과물(보정 톤, 표정, 구도 등)이 불만족스러워, 이를 **완전히 대체할 새로운 사진**을 찾는 고객.
- **구체적 상황 (Situation):**
  - "보정이 너무 과해서 딴 사람 같음."
  - "표정이 굳어서 자연스러운 컷이 하나도 없음."
  - "사설 보정 업체에 맡기자니 또 비용이 듦."
- **핵심 니즈:** 리스크 없이 즉시 확인 가능한 **고품질의 대체 사진** 확보.

### 🥉 3순위: 촬영 대체형 (The Studio Skipper)

> **"복잡하고 비싼 촬영은 싫어요. 딱 필요한 사진만 있으면 돼요."**

- **정의:** 비용 절감, 시간 부족, 혹은 촬영 과정 자체에 대한 거부감(카메라 울렁증 등)으로 **스튜디오 촬영을 생략**하고 AI로 해결하려는 실속파.
- **구체적 상황 (Situation):**
  - "결혼식 사진에 수백만 원을 쓰는 게 아까움."
  - "모바일 청첩장용 사진 5~6장이면 충분함."
- **핵심 니즈:** 최소한의 투자로 결혼 준비의 **필수 요건(청첩장 사진) 해결**.

## 3. 사용자 경험 (UX Scenario)

사용자는 복잡한 도구를 다루는 것이 아니라, **'AI 작가에게 1:1로 케어 받는 프리미엄 촬영'**을 경험합니다. 귀찮은 과정은 AI가 대신 처리하고, 대기 시간은 엔터테인먼트로 승화시키며, 결과물은 즉시 공유 가능한 숏폼 형태로 제공합니다.

### Step 1: Guidance & Upload (데이터 수집)

**"사용자는 던지고(Bulk), AI가 분류한다(Sort)"**

- **목표:** 사용자의 선별 스트레스를 최소화하면서도, LoRA 학습에 필요한 '입체적 데이터' 확보.
- **UX Flow:**
- **Role Separation:** 신랑 / 신부 탭을 명확히 분리하여 혼동 방지.
- **Interactive Guide:** 긴 텍스트 대신 **3초 루프 움짤(O/X)**로 직관적인 가이드 제공. (선글라스/마스크 착용 금지 등)
- **Bulk Select:** 카테고리 구분 없이 갤러리에서 **20~30장 한 번에 선택**.

- **AI Auto-Sorting (Client-side):** 업로드 즉시 얼굴 각도(Yaw)와 표정을 분석하여 자동 분류.
- `Bucket A (정면)`: 8~10장 목표.
- `Bucket B (반측면)`: 6~8장 목표 (입체감 및 3D 일관성 핵심).
- `Bucket C (표정/기타)`: 나머지.

- **Validation:**
- **Gap Filling:** 부족한 각도가 있을 경우에만 콕 집어 요청 (예: "정면은 완벽해요! **옆을 보는 사진 3장**만 더 넣어주세요").
- **Soft Pass:** 15장 이상이면 진행 허용 (넛지 메시지: "지금도 가능하지만 5장 더 채우면 퀄리티 UP!").

### Step 2: Optimization (데이터 최적화)

**"AI Director's Cut: 옷은 가리고, 구도는 살린다"**

- **목표:** 동일 의상 과적합(Overfitting) 방지 및 대두샷(Face-only) 방지를 위한 데이터 전처리.
- **핵심 기능: Smart Mix (하이브리드 크로핑)**
- 동일 의상/배경이 50% 이상 감지될 경우 자동 발동.
- **Face Focus (60%):** 목/쇄골 위 타이트 크롭 (의상 정보 제거, 얼굴 디테일 학습).
- **Structure Focus (40%):** 어깨/가슴선 포함 루즈 크롭 (신체 구조 및 구도 다양성 학습).

- **UI 구성:**
- **Interactive Mosaic:** 크기가 다른 썸네일(정사각형+직사각형)로 시각적 다양성 부여.
- **One-touch Edit:** 사진 터치 시 `[줌인(얼굴)] ↔ [줌아웃(상반신)]` 모드 즉시 전환.

- **진입 연출:** "AI 작가님이 조명과 구도를 체크하고 있습니다..." (스캐너 효과).

### Step 3: Theme Selection (테마 선택)

**"내 얼굴을 미리 보는 인터랙티브 쇼룸"**

- **목표:** 정적인 썸네일의 한계를 넘어, '내가 주인공이 된 모습'을 상상하게 하여 구매 전환 유도.
- **테마 구성 (MVP 3종):**
- `[A] 화이트 스튜디오`: 깔끔, 미니멀, 자연광.
- `[B] 가든 스튜디오`: 초록 정원, 따뜻한 햇살, 보케(Bokeh).
- `[C] 클래식 스튜디오`: 웅장함, 샹들리에, 호텔 예식.

- **UX 요소:**
- **Motion Thumbnail:** 정지 이미지가 아닌 **시네마그래프(움직이는 영상)** 배경 적용.
- **Floating Bubble:** 내 얼굴(Step 1 베스트컷)을 꾹 눌러 테마 모델 위에 오버레이(가상 피팅).
- **Interactive Lookbook:** [자세히 보기] 클릭 시 바텀 시트가 열리며 테마별 8종(전신/클로즈업 등) 샘플 확인.
- **AI Curation:** 사용자 이미지 분석(미소/시크 등)에 따른 'AI 추천' 뱃지 노출.

### Step 4: Shooting (촬영 대기)

**"2-Phase 전략: 지루함은 버리고, 하이라이트는 챙긴다"**

- **Phase 1: 학습 구간 (10~15분)**
- **상태:** LoRA Training (가장 긴 대기 시간).
- **UX:** "작가님이 두 분의 얼굴을 익히고 있어요. **앱을 닫고 편히 쉬세요.**"
- **Retention:** `🔔 촬영 시작 알림 받기` (Default ON).

- **Trigger (중간 알림):** 학습 완료 즉시 푸시 알림 발송 ("📸 촬영 스탠바이! 실시간 화보가 나오고 있어요").
- **Phase 2: 실시간 촬영 구간 (5분)**
- **상태:** Image Generation (순차적 생성).
- **UX (Live Darkroom):**
- **Drop & Blur:** "찰칵" 소리와 함께 사진이 트레이로 떨어지되, **블러 처리된 썸네일**만 노출 (스포일러 방지 + 기대감 증폭).
- **Detailing:** 블러 이미지 위로 빛 효과가 지나가며 "디테일 보정 중..." 메시지 노출.

### Step 5: Develop & Share (결과 및 공유)

**"언박싱의 감동을 인스타 스토리로 직행"**

- **The Reveal (언박싱):** 고급스러운 왁스 실링 편지 봉투가 뜯어지며, 빛(Bloom Effect)과 함께 결과 화면 진입.
- **Gallery View:** 핀터레스트 스타일의 세련된 그리드 배치 (고화질 다운로드/재생성 제공).
- **Killer Feature: Viral Movie Maker**
- **기능:** 베스트 5~7컷을 AI가 선별하여 **15초 세로 영상(Reels/Shorts용)** 자동 생성.
- **연출:** 테마별 맞춤 BGM + 트랜지션(Light Leak, Dissolve) + Ken Burns(Zoom) 효과 적용.
- **Action:** `🎬 내 무비 영상 보기` → **`인스타그램 스토리에 공유하기`** (원클릭).

- **AS 정책 (Re-roll):** 갤러리 하단 `🔄 아쉬운 사진 다시 찍기` (1회/4장 무료) 제공.

## 4. 핵심 기술 명세 (Technical Specs)

커스텀 워크플로우(Impact Pack)의 완벽한 제어와 즉각적인 사용자 반응 속도를 위해 **Modal Native 파이프라인**을 구축합니다.

### 4.1 AI Engine & Infrastructure

- **Infrastructure:** **Modal (Serverless GPU Cloud)**
  - **Role:** 고부하 이미지 생성 및 커스텀 노드(FaceDetailer 등) 실행 전용 백엔드.
  - **Deployment:** Python Code-base Infrastructure (`@app.cls`, `modal deploy`).
- **Core Model:** `Flux.1 Dev` (FP8 Quantization) + `Impact Pack` (Face/Hand Detailer).
- **LoRA Training:** **Fal.ai** (학습 속도 및 안정성 우수, 학습 완료 후 결과물만 Modal로 이관).
- **Database:** **Supabase** (유저 정보, 결제 내역, 학습된 LoRA 모델 URL 매핑 저장).

### 4.2 Hardware Recommendation (GPU)

웨딩 화보의 핵심인 '얼굴 디테일 보정(Inpainting)' 과정의 병목을 해소하고, 사용자 대기 시간을 1분 내외로 단축하기 위해 고성능 GPU를 채택합니다.

- **Target GPU:** **NVIDIA A100 (80GB)** ⭐
  - _Rationale:_ Flux.1 모델과 FaceDetailer를 동시에 메모리에 올리고 고속 연산 처리 가능. A10G 대비 3배 이상의 처리 속도 확보.
- **Optimization Strategy:**
  - **Memory Snapshot:** Modal의 `enable_memory_snapshot=True` 기능을 적용하여, 컨테이너 콜드 스타트(Cold Start) 시간을 **25초 → 1~3초**로 획기적 단축.
  - **Persistent Volume:** `Flux.1` 체크포인트 및 공용 LoRA 모델을 Network Volume에 사전 적재하여 다운로드 시간 제거.

### 4.3 Workflow Strategy (Logic)

1.  **Request Handling:** Next.js 백엔드가 Supabase에서 사용자의 LoRA URL을 조회하여 Modal에 요청 전송.
2.  **Instant Wake-up:** Memory Snapshot을 통해 ComfyUI 서버가 3초 이내에 즉시 응답.
3.  **Generation Pipeline:**
    - **Base Gen:** Flux.1 Dev로 고해상도 이미지 생성 (약 20~30초).
    - **Detailing:** `FaceDetailer` (Impact Pack)가 얼굴 영역을 자동 감지하여 10~12 step으로 고속 보정.
4.  **Delivery:** 생성된 이미지를 Base64 또는 S3 URL 형태로 프론트엔드에 즉시 반환.
    - _Total Time:_ 장당 약 **20초 ~ 40초** (A100 기준).

### 6.1 상품 구성: 단계별 가격 정책 (Tiered Pricing)

사용자의 목적(단순 체험 vs 청첩장용 vs 화보 소장)에 맞춰 합리적인 선택이 가능한 **4단계 티어 시스템**을 도입합니다.

| 티어 (Tier) | 가격         | 컨셉 (Theme) | 제공 장수 | 재생성 (Re-roll) | 세부 보정 (Retouch) | 타겟 및 핵심 가치                                          |
| :---------- | :----------- | :----------- | :-------- | :--------------- | :------------------ | :--------------------------------------------------------- |
| **Free**    | **무료**     | 1개          | 4장       | ❌ 불가          | ❌ 불가             | **"일단 해보세요"**<br>결제 전 퀄리티 확인 및 신뢰도 확보  |

- **세부 보정(Retouch):** AI 작가의 수동 개입(Inpainting Request) 기능.
- **재생성(Re-roll):** 동일 프롬프트/설정으로 다시 생성하는 기능.

### 6.2 환불 정책 (Refund Policy)

**"안 닮으면 100% 환불"** 정책을 유지하되, **Free 티어 도입**으로 환불 리스크를 사전에 줄이는 구조로 개선합니다.

1.  **사전 검증 (Pre-validation):**
    - 모든 유저는 **Free 티어**를 통해 본인의 사진이 AI로 잘 구현되는지 미리 확인 가능.
2.  **환불 기준 (Paid Tiers):**
    - Basic 이상 유료 결제 후, 생성된 전체 이미지 중 **사용 가능한(본인 인식 가능한) 사진이 30% 미만**일 경우 심사 후 전액 환불.
    - **Max 티어**는 무제한 수정권을 우선 사용 후, 해결 불가 시 환불 진행.
3.  **악용 방지:**
    - 환불 승인 시 생성된 모든 이미지의 다운로드 링크 만료 및 원본 접근 차단.
